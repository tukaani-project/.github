If a security issue has been discovered, please report it privately via
email to [Lasse Collin](mailto:lasse.collin@tukaani.org)
(OpenPGP key fingerprint: 3690 C240 CE51 B467 0D30 AD1C 38EE 757D 6918 4620)
or use the *Report a vulnerability* button in the security section on GitHub.

If AI tools have been used to generate the text of the report, there must be
a short human-written preamble:

1. State that the report was generated with AI tools.

2. Describe which parts of the report have been reviewed and verified by
   a human. If you are unsure about some details, say it.

Thank you!
